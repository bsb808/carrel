# Carrel

Brian Bingham's notebook of essays and technical notes for engineering
colleagues. Live at <https://carrel.bbingham.dev>.

## Building locally

Built with [Quarto](https://quarto.org/). With the Quarto CLI installed:

```bash
quarto preview
```
